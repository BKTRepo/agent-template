## 当前验收范围

| 页面操作 | 预期结果 |
| --- | --- |
| 我的实现类 | 名称、技能类、团队、版本、状态、更新时间、操作七列 |
| 开发流程栏 | 新建技能类 → 挂载知识/文件 → 自测调试 → 上线，四步 |
| 草稿修改/删除 | 保存后列表更新、刷新保留；删除需确认，取消保留 |
| 在线调试 | 对话/文档输入、当前构建完整定义、挂载资源只读、模拟结果展示 |
| 自测通过 → 上线 | 当前构建通过后“上线”按钮可用；点击直接显示已上线，刷新保留 |
| 自测失败/超时 | 保持未上线，禁止上线；修改输入后旧结果失效 |
| 已上线详情保存修改 | 校验八字段，保存编辑稿；当前线上构建保留，真实发布策略由接口处理 |
| 已上线详情下线 | 二次确认；取消保持上线；示例确认后变已下线；可重新编辑/生成/自测/上线 |
| 旧版本数据 | 等待记录转回调试中/草稿并重新自测；已上线/已下线状态不变，表单与资源保留 |

## 演示步骤

1. 点击新建技能类，填写名称、描述、版本、执行指令。挂载知识库/上传资源后补充资源使用说明。
2. 保存草稿后打开详情编辑，保存修改。如需验收删除，请使用自行创建的测试草稿。
3. 点击在线调试，生成示例构建后输入对话或文档。展开“模拟调试场景”验收失败、超时、成功；失败/超时不能上线。
4. 自测成功后修改输入，旧通过结果立即失效；重新运行通过后“上线”恢复可用。
5. 点击“上线”，列表直接显示已上线，无中间审批步骤或审批按钮。刷新后状态保留。
6. 点击上线记录详情，保存编辑稿、调试当前线上版本或确认下线。下线后可使用编辑稿重新生成、自测，通过后直接上线。

## 验证与对接限制

- 资源上传：单文件最大 20 MB、最多 5 个（累计已有和新增资源）；旧草稿超限资源需移除后再调试。
- `npm test`：19 项，覆盖直接上线、自测/构建绑定、过期响应保护、旧数据迁移、真实记录隔离，以及现有表单/资源/ZIP 验证。
- `npm run build`：检查 TypeScript、样式和生产构建。
- 当前沙箱和上线为本地模拟。真实记录须接入执行/直接上线/保存/下线等接口，模拟服务不会改变服务器发布状态。
- 草稿仅保存附件元信息，关闭弹窗后生成前需重选原文件；已生成完整 ZIP 的持久化不受影响。

# 2026-10-19 定稿前端更新

本轮依据《智能服务调度平台MVP需求_定稿》（V1.1，2026-10-17）、《20261016调整内容》和高保真HTML原型(1)(6)。仅修改前端仓库，分支沿用 znfwdd。此前20261016更新说明为历史记录，本轮规则以本文为准。

## 规则确认

- 用户已确认按定稿2.4实现个人权限，不引入团队成员授权或敏捷小队。开发者中心仅显示本人创建的技能；知识库仅创建者本人可编辑和重试；技能中心对所有用户开放查看、下载及允许的在线测试。
- 定稿部分字段仍沿用“仅本团队可见”旧文案。前端按本次确认的个人权限解释为“仅本人可见和挂载”；公开知识库所有用户可查看、挂载，编辑仍只限创建者本人。
- 应用选择不再按组织裁剪，改为从全量模拟目录模糊搜索、单选，不能填写不存在的值；知识库默认“全应用适用”。真实全行应用目录尚待提供同步接口。
- 技能资源单文件与总量均为50MB，不再保留旧20MB/5个限制。知识库文件按调整说明取消文件大小和数量控制，保留格式、空文件、同名及文件名校验；浏览器存储不足会显示实际错误。
- 两类版本由系统生成；前端本地演示模拟同一规则，真实服务应由后端权威分配。技能从1.0.0开始，知识库从V1.0.0开始，保存修改递增补丁位。旧记录保留已有主次版本，不因新规则重置已有数据。

## 页面与交互

### 开发者中心

- “我创建的技能”按当前用户过滤；个人身份只在顶栏演示切换器中模拟，无独立登录。
- 新增所属技能大类，选项为测试要点生成、智能用例生成、历史缺陷案例推荐、测试报告生成、测试数据构造、UI自动化脚本生成。
- 新建/编辑复用表单字段；版本显示系统提示或当前/下次版本，不可手填；描述、执行指令和大类等必填项在保存、调试前验证。
- 知识库挂载只在输入关键词后展示结果，支持多选和取消已选项，复用知识库可见性过滤。
- 每份资源独立选择参考资料、模板、静态资源、脚本分类；存在挂载/上传资源时使用说明必填。分类保存进文件元信息及ZIP清单。
- 草稿保存原文件到本机IndexedDB，关闭弹窗后可恢复；历史记录原文件缺失时提示重选。生成ZIP按分类整理，并保留知识库文件与二进制内容。
- 已上线保存修改直接更新本地记录、自动递增版本并更新示例ZIP，取代旧“编辑稿仍未生效”的交互。真实记录仍等待对应保存接口，不伪造服务器成功。下线后提供重新上线入口，进入调试、通过后点击上线。
- 调试展示Markdown只读定义，本人可编辑；未保存退出需确认。保存同步至技能记录和ZIP，更新版本，使旧调试结果失效。系统版本及名称等结构化元信息由表单控制，编辑正文同步到执行指令。
- 移除文档粘贴框和载入示例按钮，保留自然语言和文档上传。结果以可下载Markdown文档输出，成功后自动触发下载，也可重复下载；示例固定3条，限定不超过10条。失败和超时显示状态，不展示原终端日志。

### 知识库

- 创建名称、描述、标签、所属应用和至少一个文件必填；标签新建选项为通识类、自定义。新建不显示版本输入框，编辑只读展示版本及下一版本。
- 编辑摘要必填，维护人取当前创建者；编辑和查看均展示版本、维护人、变更描述组成的编辑历史，不做版本回退或对比。
- 按文件ID和元信息识别新增/变更文档，仅这些文件进入模拟处理；仅修改描述等元信息不重复处理所有文件。失败可重试，过期任务不会覆盖新文件状态。
- 提供挂载到技能入口，可搜索本人技能并挂载单个或全部筛选结果，支持名称/大类/应用/维护人筛选。挂载追加资源使用说明，递增目标技能版本，失效旧调试；多目标准备失败不会部分提交关系。
- 文件支持原件下载、文本/Markdown预览和PDF浏览器预览。Word/Excel等在线转换需要后端预览服务，目前明确提示下载原文件，不伪造转换结果。

### 技能中心和助手

- 技能中心保留上线/下线记录，下线记录禁用在线测试；调用次数无服务端统计时显示“—”。支持技能大类名称搜索、全量应用及维护人搜索选择、展开所有技能、六类展示。
- 技能详情复用开发者表单并只读；无保存、下线或Markdown编辑入口。类详情提供输入/输出Schema、类通识知识说明和实际可下载的Skill模板。
- 助手只加载启用大类下的已上线技能，加载区显示名称、描述、输入、输出；发送消息保存当轮技能信息快照。
- 增加清空聊天按钮：取消待完成回复并清空消息，保留已加载技能、当前未发送文字和待发附件。关闭助手及切换页面保留本次内存会话；刷新/关闭页面后聊天历史不保存。

## 数据迁移与接口边界

- 实现类存储升级到v4，知识库存储升级到v3，沿用旧存储键，保留已有文件元信息、构建、内容和发布状态。旧“已生成”归入调试中，旧审批等待记录重新自测。
- 不再依据原团队关系推断知识库编辑权限；优先使用已有创建者或最早创建记录。无法识别创建者的历史库保持只读，私有库不会转授当前用户，需要后续权威身份数据修复。
- 历史多应用关联保留显示，编辑时要求选择定稿规定的单个应用；历史旧分类通过兼容映射或表单重新选择进入新六类。
- 本次资料给出了字段、输入输出Schema和交互契约，但本轮未取得可直接联调的HTTP路由、请求方法、认证头和响应示例。现有旧接口适配器及其契约回归保留，不代表本次定稿服务已完成联调。
- 真实身份、全行应用、服务端唯一性/自动版本/权限、文件接收大小校验、真实向量处理、技能生成/调试/上下线和对话模型仍需后端支持。本地模拟明确标注，不把模拟处理当作真实服务成功。

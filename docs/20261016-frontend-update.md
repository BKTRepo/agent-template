# 2026-10-16 前端更新

依据：20261015优化内容(1)(1).docx、新版高保真 HTML (1)(5)，以及用户补充的技能中心“团队改所属应用”。本轮只修改前端，暂缓新增后端接口对接。

## 已实现

- 开发者中心：所属应用支持多选，选项为当前用户全部敏捷小队应用的并集及“全应用适用”；两者互斥。实现类只允许创建者本人修改、保存、删除、下线和上线。其他创建者可查看和模拟调试，结果仅留在当前详情预览，不能覆盖原记录。
- 知识库：新增所属应用多选，默认公开。公开库所有用户可查看、挂载；仅创建者所属小队成员可编辑。私有库只对该小队成员可见、可编辑、可挂载。知识库管理与技能挂载共用名称搜索及权限规则。创建时多小队用户可选维护小队，后续编辑保留原小队归属。
- 知识库表格：所属应用、引用次数（当前本地实现类引用数）、维护人、知识处理中/完成/失败；失败记录的小队成员可重试。编辑时变更摘要必填，记录每次摘要、版本、维护人和时间。按文档要求不提供版本回退。
- 全局 AI 助手：替换独立 Claude 对话台导航，各页面均有悬浮入口；可搜索并加载全量上线技能，支持连续对话及每轮手动多文件上传。关闭窗保留当前内存会话，切换页面可继续；刷新、关闭浏览器或切换演示身份后清空。新对话会取消待完成回复并清空本次消息和待发送附件。助手不将聊天内容、附件或历史写入 localStorage、sessionStorage 或 IndexedDB。
- 技能中心：团队列改为所属应用，搜索按新字段处理，与开发者中心上线记录一致。所有用户仍可查看全量技能、下载、在线测试。
- 原约束保留：不做独立登录，不上传 Docker，开发者资源单文件20MB/最多5个；知识库文件沿用50MB/最多100个/总计500MB。自测通过后直接上线，没有审批流。

## 模拟边界

- 顶栏姓名下的“演示用户”只用于本地验收，成员及应用目录为只读模拟数据，正式数据由平台身份和 ATPM 提供，不编辑 ATPM 成员/授权。
- 权限既在页面展示也在本地数据操作处校验，但不是服务器授权；真实权限必须由后端独立校验。
- 知识处理使用可控的本地成功/失败场景，任务编号可防止旧任务覆盖新编辑，刷新后可继续模拟处理。没有实际解析、向量化、容器或执行脚本。
- 助手仅返回明确标注的示例回复，不请求模型、不执行 Skill、不自动读取技能挂载文件，也不推送外部平台。
- 既有后端适配文件保留。新建与名称预检查默认使用本地流程；只有显式开启 VITE_SKILL_METADATA_READY=true 且具有既有平台会话时才可能启用旧的生成接口。本轮未定义新的服务端字段合同，也未修改后端仓库。
- 实现类存储升级到v3、知识库存储升级到v2，保留旧表单、资源、构建和发布状态。历史实现类缺失作者时沿用本机原演示用户“何安涵”；不能据此推断服务器资源真实所有权。历史知识库缺失所属应用时显示“全应用适用”，保留已有可见范围；未知历史小队不会归给当前用户。旧数据没有的历史摘要不补造。

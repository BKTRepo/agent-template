本期不需要 Docker 镜像上传。后端上传接收、构建复制已统一为每个文件最多 500,000,000 字节，不再限制所有资源合计 500MB；100 个资源等已确认工程校验继续保留。旧 `SKILL_BUILD_MAX_BYTES` 配置已移除，`.env.example` 单文件值改为 `500000000`。部署环境存在旧单文件覆盖值时需更新并重启。

本批相关测试 68 项、完整后端回归 **157 项通过**，12 项为既有依赖弃用警告；八项接口的缩小阈值边界、独立多文件限额、挂载和上传合并后的完整包均验证。前端未改动、未重测，下方 149/13 数字是上一批的历史记录。

另做实际大文件验证：

| 输入 | 本地实际结果 |
|---|---|
| 单文件 500,000,000 字节 | 生成、读取校验及 ZIP CRC 完整性检查通过 |
| 单文件 500,000,001 字节 | 拒绝，提示单个文件不能超过 500MB，半成品清理 |

使用稀疏磁盘原文件减少准备开销，生成器实际读取、复制、哈希和压缩全部字节，不是假造 size 属性。所有大文件自动清理，只保留 [报告](../output/skill-upload-limit-verification/report.json) 和 [本机复现脚本](../output/skill-upload-limit-verification/verify_large_resources.py)，这些输出不提交仓库。此项验证生成器，没有向正式服务器发送大文件；代理整体请求限制、磁盘空间和超时仍需部署环境确认。

3. **浏览器页面交互：**仅在开发者中心填写四个必填项，全部知识库不勾选，确认无附件说明可空；通过真实文件选择器上传三份测试文件，确认说明变成必填、空说明阻止提交；填写说明后提示消失。测试表单已取消，未改变用户原有列表记录。当前浏览器没有平台会话，没有注入 Token，也没有用浏览器模拟包冒充后端包。

## 新手如何复现

在 agent-template 启动现有隔离联调服务（已在运行时不要重复启动）：

```powershell
.\.venv\Scripts\python.exe -m examples.skill_integration_server
```

前端 dev 服务保持在 5174。然后在 agent-template-frontend 运行：

```powershell
node scripts/verify-skill-live.mjs
```

脚本只允许 loopback 地址，并先确认 health 为本项目本地 SQLite 服务，再使用隔离测试账号登录；不会把凭据写入浏览器。两份 ZIP 和报告保存在后端 output/skill-no-knowledge-integration。它不是生产运行脚本，不要向团队正式服务运行。

# 新 HTML 前端接口对接说明

## 开发者中心直接上线（2026-10-14）

产品改为面向测试经理，按新版 `(1)(3).html` 移除审批步骤、按钮、弹窗、模拟查询接口和当前审批状态。流程为新建 → 挂载资源 → 自测 → 点击上线。失败、超时、修改输入或构建后旧通过结果失效，不能上线。

已上线详情支持编辑八字段、保存修改、在线调试、下线二次确认；已下线详情可继续编辑并重新生成、自测通过后直接上线。示例保存修改持久化 `pendingChanges` 编辑稿，保留当前线上定义、构建、调试结果。保存编辑稿不等于重新发布；下线后继续编辑会使用编辑稿，生成新构建前清除旧上线/调试结果。

保存、直接上线和下线通过 `src/api/developerLifecycle.ts` 适配器；当前只有本地演示实现。`publishSkill` 接收当前实现类，返回实现 ID、构建 ID、调试结果 ID 和 `publication` 上线记录。`applyPublication` 再次确认当前构建与通过结果一致，才将列表状态改为已上线并持久化。真实后端记录会明确提示接口未接入，不伪造服务端上线、保存、下线或权限成功。

后端对接使用直接上线接口，不需要审批接口。请求需包含技能/构建/自测结果标识，服务端验证自测结果及测试经理权限，成功后返回发布状态与上线信息。前端采用服务端结果刷新；失败或 403 保持原状态。接口端点待后端确认，本次未修改后端，也未绕过认证。

沿用 `znfwdd-developer-center-v1` 存储键，schema 版本升级到 2。迁移移除旧审批字段；旧“待审批”记录有构建则变为调试中、无构建则为草稿，并清除旧通过结果，要求重新自测。已上线/已下线记录及用户表单、资源、构建保留。迁移不会自动发布任何等待记录。

后续接口联调项：真实列表/草稿保存/删除/修改/下线；真实沙箱、自测结果查询、直接上线；平台身份及操作权限。模拟响应禁止改变真实技能的发布状态。草稿附件原文件恢复未列入本周交付（现只持久化文件元信息，需要重新选择）。旧产品方案 DV-05 的 MCP/数据服务依赖多选尚未实现；新版八字段只有运行环境要求，是否保留独立依赖字段需产品确认。Docker 镜像入口本期取消，资源入口上传脚本、依赖包、文档和图片。

前端分支 `znfwdd`。本次只修改开发者中心相关前端，不修改团队后端。登录继续暂不开发；示例生成、调试和上线可免登录操作。

## 八字段生成

2026-10-13 老师最新资源规则：本期取消 Docker 镜像上传；开发者中心资源与调试文档单文件最大 20 MB（20 × 1024 × 1024 字节，允许等于上限）、最多 5 个（累计已有文件和本次选择）。这替代之前的单文件 500 MB 规则。旧草稿资源超过新版大小/数量限制时需移除后再调试。后端和代理需采用一致的大小和数量规则；本次仅改前端，未宣称服务端限制已同步。知识库页仍沿用原有文件规则。

`POST /skills/form/builds` 继续使用 multipart：`source` 为 JSON 字符串，`files` 为重复文件字段。

```json
{
  "skill_id": "后端技能 ID",
  "skill_name": "技能名称",
  "description": "用户填写的描述",
  "version": "用户填写的版本号",
  "instructions": "执行指令",
  "knowledge_base_ids": [],
  "resource_usage": "资源何时使用和用途",
  "compatibility": "运行环境要求"
}
```

2026-10-13：后端已接收八项合同，支持描述、版本和 GIF/SVG/WebP。开发者中心有平台会话且未选示例库时默认使用真实生成；显式 `VITE_SKILL_METADATA_READY=false` 可关闭。无平台会话仍是免登录预览，暂不增加登录页。描述与版本由用户填写，不被自动值覆盖。

知识库目前尚未开发，传空 knowledge_base_ids 即可生成；文档、图片、脚本直接通过 files 上传，不依赖知识库。已通过前端真实函数 → 5174 代理 → 8519 的无附件/直接上传/查询/下载联调，见后端 [不依赖知识库的验收记录](../../agent-template/docs/skill-no-knowledge-integration.md)。浏览器按钮的真实提交仍需统一平台会话，不能把免登录预览当真实接口验收。

真实构建详情和调试只读定义采用当前 build_id 的 source/files；查询失败或构建不匹配不展示成功结果。知识库入口保留；本批没有调整其他页面。

## 知识库

当前管理页和挂载选择器共用本地 `knowledgeStore` 与名称过滤，原文件存入 IndexedDB。真实搜索适配保留在 `src/api/knowledge.ts`，但 UI 当前统一使用本地数据。

后端需补齐知识库版本、标签、团队可见范围、向量化配置、文件列表及创建/编辑合同，再将管理页和挂载选择器整体切到服务端数据。不能只切换一处，导致新建知识库在另一处不可见。

## 调试

当前模拟输入为 `{conversation, documentText, documents}`，可同时提供多种输入，至少一项。`documents` 存储文件元信息，真实执行应使用文件 ID/上传接口传递原文件，由后端解析 PDF、Word 等内容；不能把文件名当作文件内容。

执行、上线必须绑定同一个 `buildId` 和当前通过结果 ID；输入、超时或构建变化后旧通过结果失效。真实解析、运行和直接上线接口尚未接入。

## 完整 ZIP

真实下载复用 `GET /skills/{skill_id}/builds/{build_id}/download`。后端 ZIP 包含技术名根目录中的 SKILL.md 与全部实际资源，固定生成时的资源版本；服务端构建清单通过详情接口返回，不要求加入标准下载包。

前端示例 ZIP 使用标准 UTF-8 ZIP STORE 格式，包含真实原文件字节，写入 IndexedDB 缓存；缺失资源会阻止下载。默认目录为 `references/{kbId}/`、`scripts/`、`assets/`，清单标记 `frontend-preview`。

## 使用示例

先创建技能记录，得到 `skill_id`；接着 multipart 请求中提交：

```json
{
  "skill_id": "实际技能ID",
  "skill_name": "核心系统用例生成",
  "instructions": "读取需求，按业务规则生成正向、异常和边界用例。",
  "knowledge_base_ids": [],
  "resource_usage": "rules.md 提供业务规则；check.py 校验输入；dependencies.zip 提供依赖归档。",
  "compatibility": "Python 3.12，依赖由运行环境提供。"
}
```

将上述 JSON 字符串放在 `source` 字段，多个文件放在重复的 `files` 字段。无附件时省略文件字段；无知识库或附件时说明可为空。沿用原 `token` 请求头，业务成功仍需检查 `status == success`。

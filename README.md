# 智能服务调度集前端

项目分支：znfwdd。使用 React、TypeScript、Vite、Zustand 和 Lucide，保留 HeroUI 通用组件及原工程的 CSS 兼容构建脚本。

界面依据产品 HTML 原型：深蓝左侧导航、白色顶栏、团队选择、浅色内容区，默认进入开发者中心。2026-10-14 按新版 `(1)(3).html` 调整为面向测试经理的“自测通过 → 直接上线”流程，审批环节已取消。

## 本地启动

```powershell
npm ci
npm run dev
```

开发地址通常是 http://localhost:5174，以终端实际输出为准。生产构建使用 `npm run build`，构建后可运行 `npm run serve`。

## 当前功能

- 暂不开发登录，默认直接进入开发者中心，保持 HTML 原型顶栏和导航。
- 新建技能展示八项字段：技能名称、描述、版本号、执行指令、挂载知识库、资源上传、资源使用说明、运行环境要求。
- 名称唯一校验；描述、版本与执行指令在进入调试前必填；有资源时使用说明必填。草稿允许未填完的字段，回显保留用户填写的描述和版本。
- 开发者中心上传脚本、依赖、文档和 PNG/JPG/JPEG/GIF/SVG/WebP 图片；按老师最新要求，单文件最大 20 MB（20 × 1024 × 1024 字节，含边界）、最多 5 个（包含已有资源），拒绝非法名称、未知格式、空文件和同名文件。知识库页沿用单文件 50 MB、累计 500 MB 的原有规则。
- 调试支持自然语言对话、粘贴文档文本和上传需求文档，至少提供一项；完整 Skill 定义与挂载资源只读展示。修改输入会清除旧调试结果，当前构建通过后可点击“上线”。失败/超时/过期结果不能上线。
- 开发者中心支持草稿修改/删除、已上线技能保存编辑稿和下线确认。上线直接更新列表并持久化；无提交审批、查看审批或审批状态。
- 本地数据版本升级到 2；原“待审批”记录保留表单/资源/构建，转为调试中或草稿，清除旧通过结果后重新自测。原已上线/已下线状态保留，旧审批字段移除。
- 知识库管理只保留知识库列表及库内文件，不设置独立文件资源库。支持名称模糊搜索、创建和本团队编辑，版本号必填，其他团队只读。
- 管理页与挂载选择器共用 knowledgeStore 和过滤逻辑，新增知识库可以立即搜索挂载。
- 技能中心按技能类分组，支持搜索、详情、在线测试和整个 ZIP 下载；默认展示两个明确标注的已上线示例，新上线记录可进入列表。
- 示例 ZIP 包含 SKILL.md、全部知识库文件、上传文件和 manifest.json；保存生成时的资源副本，知识库修改不改变已生成包。文件缺失时提示补充原件，禁止静默遗漏资源。
- 文本和列表存入 localStorage；知识库原文件及生成 ZIP 存入 IndexedDB。刷新可恢复。草稿仅保存资源元信息，关闭编辑后生成前需重选原文件。

没有平台会话时生成使用本地演示；调试、上线、知识库管理及向量化配置仍为明确标注的本地演示。示例 ZIP 是实际可解压的文件，但没有模型生成或脚本执行。真实生成、查询及 ZIP 下载封装保留。真实记录需接入上线接口，不会由模拟服务修改其发布状态。其他未开发模块继续展示占位提示。

本周只完善开发者中心的模拟前端交互，操作步骤见 [开发者中心验收清单](docs/developer-center-acceptance.md)。草稿附件自动恢复、独立 MCP 依赖选择不在本次范围。Docker 镜像入口已按产品要求取消，资源上传继续支持脚本、依赖包、文档和图片。

## 本地前后端联调

先在后端 `agent-template` 目录启动隔离的联调服务：

```powershell
.\.venv\Scripts\python.exe -m examples.skill_integration_server
```

服务监听 `127.0.0.1:8519`，使用现有登录和 Skill 路由以及本地 SQLite，不连接团队数据库。数据、构建包及本地 JWT 密钥保存到后端忽略目录 `output/skill-integration/`。此入口仅用于本机联调。

已有本地库需要名称键迁移，新建库由模型建表。迁移、备份及正式 Aerich 协调见后端 `docs/skill-form-validation-progress.md`；当前本机旧库已迁移，并建立经完整性检查的迁移后快照。

前端 `npm run dev`、`npm run preview` 和 `npm run serve` 均保留接口代理。页面目前无需登录，也不展示登录页或退出登录按钮；后续统一接入平台身份体系。没有平台会话时，新建、生成、沙箱调试及上线使用模拟流程。真实接口的后端认证机制保持不变，已有会话仍可用于查询及下载。有平台会话且未挂载示例知识库时可使用八字段真实生成；显式设置 VITE_SKILL_METADATA_READY=false 可关闭真实生成。八字段合同及联调说明见 docs/frontend-api-handoff.md。

填写技能名称、描述、版本号和执行指令后点击“调试”，生成完整示例包后进入模拟沙箱。上传资源或选择知识库时还需填写资源使用说明；该说明以 resource_usage 独立提交后端。运行环境要求选填。开发者中心资源单个不超过 20 MB、最多 5 个，批量选择和后续追加均累计计数。同名文件不可重复添加；保存草稿会保留文件名、大小、修改时间和说明，关闭弹窗后需重新选择原文件，或移除缺失文件。JWT 保存在标签页会话存储中，密码不保存。

`src/api/skillClient.ts` 负责认证、生成、查询、下载及字段错误映射；`src/api/developer.ts` 保留模拟调试；`src/api/developerLifecycle.ts` 提供直接上线及上线维护适配器；`src/stores/developerStore.ts` 管理本地列表。真实包存储及查询由后端负责，列表跨账号隔离和服务端草稿管理尚未接入。

前端目录与后端 `agent-template` 目录独立，分别在 `znfwdd` 分支工作。正式部署时将代理目标改为正式后端，并完成 MySQL、用户体系、资源库和运行模块的接入验证。
